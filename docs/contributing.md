# Contributing

Development is ongoing and contributions are very welcome. Coordination happens via the source code repository at https://hub.psychoinformatics.de/datalink/shacl-vue. Please have a look at the [open issues](https://hub.psychoinformatics.de/datalink/shacl-vue/issues) to see if your question has already been brought up before. If not, please create a new issue for discussion.
